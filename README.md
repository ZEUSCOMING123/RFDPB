## 📌 About

RFDPB is a random fact giver Discord bot written in Python.  
The name stands for **Random Facts Discord Python Bot**.

It is a minimal and basic project for learning Discord bot development.

---


## 🚀 Installation



### 🇺🇸 English:
Install RFDPB with https:

```bash
  git clone https://github.com/ZEUSCOMING123/RFDPB.git
  cd RFDPB
  pip install discord.py python-dotenv requests
```
Run The English Version:

```bash
  cd RFDPB
  python main_us.py
```

### 🇹🇷 Turkish:

```bash
  git clone https://github.com/ZEUSCOMING123/RFDPB.git
  cd RFDPB
  pip install discord.py python-dotenv requests deep-translator
```

 Run The Turkish Version:

```bash
  cd RFDPB
  python main_tr.py
```
    
### 2. Environment Variables

To run this project, you will need to add the following environment variables to your .env file


```bash
  DISCORD_TOKEN=(discord-token-here)
```
